# ODPTデータ確認メモ（2026-09-20）

この文書は、実装する前に確認した公開カタログの範囲を記録するものです。APIのURL・レスポンスフィールド・取得可否を推測して実装するための文書ではありません。

## 確認できた公開カタログ上の対象

小田急電鉄の組織ページには、2026年9月20日現在、次の4データセットが掲載されている。

| データセット | このアプリでの候補用途 | 状態 |
| --- | --- | --- |
| 駅情報 | 駅名、運営者、路線、識別子の照合 | 導入候補 |
| 路線系統情報 | 江ノ島線などの路線・駅の関係 | 導入候補 |
| 駅時刻表 | 平日の出発候補、種別、方向、番線が提供される場合の照合 | 導入候補 |
| 乗降者数情報 | 対象外（将来の混雑注意表現の検討材料にはなり得る） | 今回は使わない |

いずれも「公共交通オープンデータチャレンジ限定ライセンス」と表示されている。アプリ化前に、該当年のライセンス全文と各データセットの個別条件を再確認する。

## 公開カタログで確認できなかったもの

小田急組織の一覧では、列車ロケーション、駅施設、構内徒歩経路グラフのデータセットは確認できなかった。この「ない」は当該公開カタログ一覧における観測結果であり、非公開データや将来追加の存在を否定するものではない。

そのため以下はODPTの自動化対象にしない。

- 到着ホームから西口改札・出口までの連続した構内歩行案内
- 階段、エスカレーター、エレベーターを使う順序
- 駅出口から大和市渋谷学習センターまでの歩道・横断箇所

これらは `StationGuide` / `WalkingRoute` の確認済みレコードとして、人が公式根拠を確認して登録する。

## 高座渋谷駅の公式根拠として確認できたこと

小田急電鉄の高座渋谷駅ページには、駅立体図、ホーム図、バリアフリー経路、階段、エスカレーター、エレベーターの案内がある。改札口から上下ホームへはスロープとエレベーターがある旨も掲載されている。

ただし、ページのテキスト取得だけでは「ホーム中央」から「西口改札」へ至る具体的な順序や、図上の経路を機械的に確定できない。現在のfixtureの駅構内文は `needs-review` のままとし、紙に載せる前に公式図を目視確認し、確認者・確認日・根拠URLを記録する。

## 実接続へ進む前のゲート

1. ODPT登録を済ませ、チャレンジ2026用のアクセス方法・トークン保管方法を確認する。
2. サーバー側で実データを取得できる環境を用意する。ブラウザへトークンを出さない。
3. 駅情報・路線系統情報・駅時刻表の実レスポンスを保存し、提供されるフィールドと更新情報を確認する。
4. `GuideRepository` のODPT実装を、その確認済みスキーマだけで作る。
5. 実時刻を紙に使う場合は、取得日時・データ生成時刻・有効範囲を画面と印刷物に表示する。
