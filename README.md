# 迷わないおでかけ紙 — 駅構内オープンデータで案内を自動生成

**電車を降りてから、出口まで。**

「迷わないおでかけ紙」は、高齢者を主な利用者として、駅構内のオープンデータを利用して、電車を降りてから目的の出口までの経路を、紙の案内として自動生成するWebアプリです。駅構内の案内と出口から目的地までの地図を、A4両面の紙面にまとめます。現在は都営大江戸線の12コースを収録しています。任意の駅や目的地を検索するサービスではありません。

## なぜ作ったのか

一般的な乗換案内から電車や出口は分かっても、到着後に「ホームからどちらへ進み、どの改札を通って、目的出口へどう行くか」を判断するのは簡単ではありません。構内図を見ながらスマートフォンを操作し続ける負担を減らし、出発前に確認できる案内を作ることを目指しています。

根拠が確認できる場合は、設備、階、改札後の方向などを具体化します。根拠が足りない場合は、設備や方向を決めつけず、より抽象的な案内へ戻します。常に特定のエレベーターや改札名まで案内できるわけではありません。

## なぜ紙なのか

出発前に確認して印刷でき、駅構内でスマートフォンを操作し続ける必要がありません。表面を列車と駅構内、裏面を出口から目的地までの地図に分け、比較的大きな文字で次の行動を追える構成にしています。

## この経路をどう選んでいるのか

先に「エレベーターにする」「エスカレーターにする」と設備だけを決めるのではなく、ホームから目的出口までの候補経路を作り、設備を使った後の通路も含めた経路全体を比較します。

現在の紙面生成処理では、各乗車位置（boarding area）と目的出口について、概ね「最短」「階段回避」「エレベーター優先」「エスカレーター優先」の探索設定から候補を集めます。これらは候補を探すための設定であり、4つが必ず異なる経路になるわけではありません。同じ乗車位置・出口・Pathway列になる重複候補はまとめます。

候補は単純な最短距離順では選びません。まず階段利用、設備種類の切り替え、分岐や判断が必要になる箇所の目安を比較します。その上で、候補群の最小距離 `Dmin` を基準に `Dmin + 10m` 以内を距離的に近い候補群とし、その中で案内上の行動として観測した設備利用などを比べます。balanced選択ではエスカレーター利用を弱い同点要素として扱い、最後は距離などと有向Pathway列を使った再現可能な決定規則で選びます。

赤羽橋の同じ乗車位置から同じ出口への候補比較では、次の2経路が確認されています。

| 候補 |   距離 | 階段 | ES（案内上の観測） | balancedでの扱い |
| ---- | -----: | ---: | -----------------: | ---------------- |
| A    | 139.7m |    2 |                  2 | 選択されない     |
| B    | 142.6m |    1 |                  3 | 選択             |

Bは2.9m長い一方、階段利用を1回減らします。候補全体の比較では、距離差より階段負担を優先した例です。ESの数は経路の案内表現から数えた観測値で、実際のエスカレーター設備を1基ずつ数えた確定値ではありません。

### 候補探索の限界

現在の紙面生成処理は、全経路を列挙する探索ではなく、限られた探索設定から候補を作ります。そのため、出口までの別のエスカレーター／エレベーター経路が候補に入らず、比較対象から漏れる可能性があります。比較検証用の探索（shadow）では、現在の紙面生成処理の候補にない別Pathway列も確認されています。「必ず最適」「すべての設備経路を比較」とは言えません。現在は紙面生成処理と切り離した比較検証用の探索で、候補の広がりや選択の安全性を検証しています。

## 紙面の構成

### 表面 — 列車と駅構内

上部に「乗る／降りる」の左右ブロックを置き、出発駅・発車時刻、路線・行先、乗車ホーム、根拠がある場合の号車位置と、到着駅・到着時刻・到着ホームを表示します。到着ホームの物理階名は、公式Floor情報で確認できる場合だけ加えます。

その下に目的出口と、到着ホームから出口までのStationGuideを表示します。案内は「1 step = 1 action」を基本にし、改札通過と改札後の方向転換など、別々の行動は根拠があれば分けます。

### 裏面 — 出口から目的地

駅出口、目的地、ゆっくり歩く目安時間、固定の徒歩地図と徒歩経路線を表示します。逐次的な徒歩案内文は表示しません。屋外の徒歩経路形状は固定データで、実行時に経路検索APIから取得するものではありません。

## 経路生成の流れ

```text
静的な列車時刻データ
  → 登録済みのホーム・乗車位置
  → GTFS-Pathways graph
  → 経路候補の生成
  → balancedで経路を選択
  → 案内ステップを意味単位に整理
  → 根拠が確認できた情報で補強
  → A4表裏のStationGuide・地図
```

駅構内の経路トポロジーの正本はGTFS-Pathwaysです。StationMapやwalking networkで経路を置き換えるのではなく、対応が確認できた範囲で意味付けや案内表示を補助します。

## 分からないものを推測しない

案内の具体性よりも、根拠の強さを優先します。

- GTFS `level_index` は相対的な階層情報として扱い、値から「地下2階」などの物理階名を推測しません。
- 物理階名は、対応が確認された公式Floor情報がある場合に表示します。
- 最近傍のFacility、同じSpace、近接、同じ設備種別だけでは、同じ物理設備だとは断定しません。
- 階段・ES・EVの方向や設備個体を確定できない場合は、不明または汎用的な表現に戻します。

この方針は、情報が豊富な駅だけでなく、データが部分的な駅でももっともらしい誤案内を避けるためのものです。

## 汎用エンジンと安全な補強

構内経路選択・紙面生成の実行時処理では、駅IDによる特殊分岐を原則として持ちません。駅IDは固定データ（fixture）、StationMap登録、公式メタデータなどのデータキーとして使います。駅固有なのは主にデータで、利用可能なFacility／Space／Floor情報に応じて案内を補い、情報がなければGTFS中心の基本案内に戻します。

対応関係を確認できたPathwayだけ、walking network由来の設備・方向情報を補助に使います。この対応表は部分的で、全Pathwayに対応があるわけではありません。設備の連続性を示す根拠を扱う仕組みもありますが、強い設備同一性の根拠がない場合、連続する同種の経路要素を物理的なエレベーター1基などと数えません。

SAFE REJOINは、同じ階にいることだけを根拠に案内を再接続するものではありません。候補経路どうしで同じ意味上の改札境界を通ることと、経路順序が確認できた場合に限り、その改札境界の後で共通の詳細案内へ戻します。

架空駅を使う `src/domain/newStationOnboarding.test.ts` では、未知の駅IDに対してGTFSのみの基本案内、登録データがある場合の案内ステップの整理、データ不足時に簡略な案内へ戻る動作を検証しています。これは新駅のデータを加えるだけで公式案内まで自動的に完成する、という保証ではありません。

## 実験中の経路探索

より多くの候補経路を比較するための探索方法も、現在の紙面生成処理とは分離して検証しています。multi-objective routing、origin別multi-target探索、目的出口向け `g+h` queue ordering、evidence-aware selection、shadow cutover gate などが含まれます。これらは現時点で公開紙面の経路選択には使っていません。探索予算に達すると `complete=false` になることがあり、全Pareto経路を列挙する機能ではありません。

`balanced`、`escalator-preferred`、`elevator-preferred` のMobilityProfileもdomain側にありますが、利用者向けUIの選択機能ではありません。現在のUIはbalancedを使い、12コースのprofile比較監査では選択経路の差は確認されていません。

## 時刻表と現在の制約

列車検索は静的な平日時刻表を使うデモ設定です。現在の初期検索条件は **2026-09-21 07:00** で、UIから日付・時刻は変更できません。静的GTFS fixtureの有効期間は **2026-03-14〜2026-12-31** です。リアルタイム運行情報はありません。

- 登録済みの都営大江戸線12コースが対象で、任意駅・目的地検索はありません。
- 現在の候補探索は限定的で、全経路の列挙や大域最適を保証しません。
- 号車位置や公式設備情報は登録されたデータの範囲に限られます。
- Pathway対応表や設備同一性の根拠は部分的です。
- ES／EVの優先設定を利用者が選ぶUIはありません。
- 比較検証用の経路探索は現在の紙面生成には使っていません。
- 裏面は地図中心で、逐次的なturn-by-turn徒歩案内はありません。

## 使い方

1. 行きたいコースを選びます。
2. 「検索」を押すと、乗る列車と到着駅での構内案内が表示されます。
3. 表面で、乗車駅・列車・到着ホーム・目的出口までの進み方を確認します。
4. 裏面で、駅出口から目的地までの徒歩地図を確認します。
5. 必要に応じてA4両面で印刷して持ち歩きます。

現在は登録済みの都営大江戸線12コースを体験できます。
